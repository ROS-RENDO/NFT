# TechTuneNFT Marketplace

A fully functional, decentralized NFT marketplace DApp where users can mint, buy, and list digital assets on the Ethereum blockchain directly from their web browser.

## ✨ Features
- **Mint NFTs**: Upload an image URL, set a price, and mint a brand new ERC-721 token.
- **Buy NFTs**: Browse the global marketplace and purchase NFTs securely.
- **Sell/List NFTs**: List your owned NFTs for sale on the marketplace.
- **Secure Escrow**: The smart contract acts as a secure escrow during listings, ensuring trustless transactions.
- **Live Balances**: Real-time ETH balance tracking directly in the user interface.

## 🛠️ Tech Stack
- **Blockchain**: Solidity, Hardhat, Local EVM Node
- **Frontend**: React.js, Vite, Ethers.js (v6)
- **Styling**: Custom Glassmorphism UI (Vanilla CSS)
- **Wallet Provider**: MetaMask

## 🚀 Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/ROS-RENDO/NFT.git
cd NFT
```

### 2. Start the Local Blockchain (Backend)
Open a new terminal window, navigate to the `blockchain` folder, and start the local node:
```bash
cd blockchain
npm install
npx hardhat node
```
*(⚠️ Keep this terminal running! It provides the local test network and 20 test accounts loaded with 10,000 fake ETH.)*

### 3. Start the Web App (Frontend)
Open a **second** terminal window, navigate to the `frontend` folder, and start the development server:
```bash
cd frontend
npm install
npm run dev
```
*(Your frontend will now be running at `http://localhost:5173`)*

## 🦊 How to connect MetaMask for Testing

Because we are using a local development network, you need to tell your MetaMask wallet to connect to it.

### Step 1: Add the Local Network
1. Open the MetaMask extension in your browser.
2. Go to **Settings** -> **Networks** -> **Add Network** -> **Add a network manually**.
3. Enter the following details:
   - **Network Name**: Hardhat Localhost
   - **New RPC URL**: `http://127.0.0.1:8545`
   - **Chain ID**: `31337`
   - **Currency Symbol**: `ETH`
4. Click **Save** and make sure you switch to this new network.

### Step 2: Import Test Accounts (To get 10,000 ETH)
To interact with the DApp without spending real money, you need to import the secret test accounts generated by your Hardhat node:
1. In MetaMask, click the account dropdown at the top and select **Add account or hardware wallet** -> **Import Account**.
2. Look at the terminal where your Hardhat node is running. It will display a list of Accounts and Private Keys.
3. Copy the **Private Key** for Account #0 (starts with `0xac09...`).
4. Paste the Private Key into MetaMask and click **Import**.
5. You will instantly see **10,000 test ETH** in your wallet!

*Repeat Step 2 with Account #1 to have a second wallet so you can test buying and selling between two different people.*

## 📝 Common Issues
- **MetaMask gets stuck on transactions:** If you restart the Hardhat node, MetaMask's internal transaction history gets out of sync. To fix this, go to MetaMask -> Settings -> Advanced -> **Clear activity tab data**.
- **Error: evmVersion cancun:** If you get deployment errors, ensure your `hardhat.config.js` is set to `evmVersion: "cancun"`.
